# AI Chatbot Assistant (Version 2.0.0)

A highly polished, secure, and lightweight AI Chatbot built from the ground up with a **C++17 backend server** and a **Vanilla HTML/CSS/JS frontend**. 

This application connects to the **Groq API** for lightning-fast AI text and vision responses. It also features a seamless, intelligent local fallback system that uses a local text-based Knowledge Base when the API is disconnected or unavailable.

---

## 👶 New to Programming? Start Here!
**What does this project actually do?**
Think of this project as your own personal version of ChatGPT, but hosted entirely on your own computer. 
- The **Frontend** (HTML/CSS/JS) is the beautiful webpage where you type your messages.
- The **Backend** (C++) is the "brain" running invisibly on your computer. When you send a message, the webpage sends it to the C++ brain. The C++ brain then securely forwards it to Groq's supercomputers, gets the AI's answer, and sends it back to your webpage!
- If the internet goes down, the C++ brain reads from local `.txt` files on your computer to try and answer your questions offline.

---

## 🛠️ Complete Tech Stack & Libraries Used

### Backend (Server)
- **Language:** C++17 (compiled via MinGW-w64 / MSYS2 on Windows).
- **cpp-httplib (`httplib.h`):** A lightweight, single-header C++ library used to create the multi-threaded HTTP web server that serves the HTML UI and handles REST API routes.
- **nlohmann/json (`json.hpp`):** A single-header C++ library used for parsing incoming JSON requests from the frontend and building JSON payloads to send to Groq.
- **libcurl:** The standard C URL transfer library, used by the backend to make outgoing HTTPS POST requests to the Groq API.

### Frontend (User Interface)
- **HTML5 & CSS3:** Completely custom-built styling using CSS Variables for theming (allowing easy switching between light/dark themes) and Flexbox for responsive layouts.
- **Vanilla JavaScript (`script.js`):** Handles all DOM manipulation and fetch requests without heavy frameworks like React.
- **marked.js (v14):** Loaded via CDN. Converts the raw Markdown text generated by the AI into beautiful HTML elements.
- **highlight.js (v11.8.0):** Loaded via CDN. Automatically detects code blocks in the AI's response and applies syntax highlighting.

## 🗄️ Database & File Management

The application does not require a bulky SQL database. Instead, the C++ server dynamically generates and manages secure flat-text files in the same directory as the `.exe`. 

1. **`api_key.txt`**: Stores your Groq API key securely.
2. **`chat_history.txt`**: Stores ongoing conversation histories for the sidebar.
3. **`saved_answers.txt`**: Stores AI answers you have specifically pinned/saved.
4. **`knowledge.txt`**: Stores the Admin-created Offline Fallback Q&A database.

## 📡 REST API Reference (For Developers)

The C++ backend exposes the following RESTful API endpoints for the frontend to consume:

| Method | Endpoint | Description |
|--------|----------|-------------|
| **POST** | `/api/chat` | Receives user messages, contacts Groq API, or falls back to local knowledge. |
| **GET** | `/api/history` | Returns all saved conversation history from `chat_history.txt`. |
| **DELETE**| `/api/history` | Deletes a specific conversation or clears all history. |
| **POST** | `/api/saved` | Pins a specific AI answer to `saved_answers.txt`. |
| **GET** | `/api/apikey` | Returns the currently saved API key (masked for security). |
| **POST** | `/api/apikey` | Saves a new Groq API key to the local machine. |
| **POST** | `/api/admin/login` | Authenticates admins using a secure token mechanism. |
| **POST** | `/api/knowledge/add` | (Admin) Adds a new Q&A rule to the offline database. |

## ⚙️ How to Compile the `.exe` File (Beginner-Friendly Guide)

To run the C++ server, you must compile `chatbot.cpp` into a Windows executable (`.exe`). Because this project relies on web libraries (`libcurl`), we use an environment called **MSYS2**.

### Step 1: Install MSYS2 & Dependencies
1. Download and install [MSYS2](https://www.msys2.org/).
2. Open the program called **"MSYS2 UCRT64"** (a black terminal window).
3. Copy and paste this command into the terminal and hit Enter to install the C++ compiler:
   ```bash
   pacman -S mingw-w64-ucrt-x86_64-gcc
   ```
4. Copy and paste this command to install the networking library:
   ```bash
   pacman -S mingw-w64-ucrt-x86_64-curl
   ```

### Step 2: Compile the Code
1. Tell the terminal to go to the folder where your code is saved:
   ```bash
   cd "e:/Creative Techno College/Technocrats/Projects/Project List/ChatBot/Source"
   ```
2. Copy and paste this exact command to compile the code into an `.exe` file:
   ```bash
   g++ -std=c++17 -O2 -I. chatbot.cpp -o chatbot.exe -static-libgcc -static-libstdc++ -lcurl -lws2_32 -lwinpthread
   ```

### Step 3: Run the Server
Once compiled, you will see a new `chatbot.exe` file in your folder. Start the server by typing:
```bash
./chatbot.exe
```
Open `http://127.0.0.1:8080` in your web browser (Chrome, Edge, Safari) and your chatbot is ready to use!

## 🔒 Security Architecture (v2.0.0 Audit)

- **API Key Masking:** When the frontend requests the API key, the backend intercepts it and sends `gsk_********************`. The true key is never exposed to the browser inspector.
- **XSS Prevention:** All raw HTML sent by the user or AI is sanitized via strict escape functions in JavaScript before being rendered by the Markdown parser, completely eliminating Cross-Site Scripting (XSS) risks.
- **Rate Limiting:** Administrative endpoints are protected against brute-force attacks via memory-based IP lockouts.
