Project Overview

Chatbot Assistant is a conversational application developed as a Semester 2 academic project. It processes user input using keyword matching and predefined question-and-answer patterns, maintains conversation history, manages a file-based knowledge base, and integrates the Groq API for AI-powered responses.

Key Features

Smart Conversation Enables interactive, text-based communication between users and the chatbot.
Automated Responses Provides predefined and relevant responses to commonly asked questions.
Greeting & Goodbye Detection Identifies common greeting and goodbye messages and responds appropriately.
Keyword Matching Analyzes user input to identify relevant keywords and patterns for response generation.
Knowledge Base Stores, retrieves, and manages questions and answers using file-based data storage.
Q&A Management Allows questions and corresponding responses to be added and updated within the knowledge base.
Conversation History Records and displays previous messages for easy reference and continuity.
AI-Powered Responses Uses the Groq API to generate AI-powered responses for questions requiring AI assistance.
Export Chat Allows users to select and export conversations as readable text files for backup and reference.
